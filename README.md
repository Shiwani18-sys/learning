# Learning

Today, I focused on strengthening my understanding of **Git and GitHub** and explored some of the important features used in real-world development workflows.

### Topics Covered

- **Git Stashing**
  - Learned how `git stash` temporarily stores uncommitted changes.
  - Understood how to use `git stash`, `git stash list`, `git stash apply`, and `git stash pop`.
  - Learned when stashing is useful while switching branches or working on multiple tasks.

- **Git Tags**
  - Learned about Git tags and their purpose.
  - Understood how tags can be used to mark important points in the repository, such as software releases.
  - Practiced creating and viewing tags using commands like `git tag` and `git tag <tag-name>`.

- **Git Rebase**
  - Learned the concept of rebasing in Git.
  - Understood how `git rebase` helps maintain a cleaner and more linear commit history.
  - Learned the basic workflow of rebasing branches and handling potential conflicts.

- **GitHub Repository Hosting**
  - Learned how GitHub is used to host Git repositories remotely.
  - Practiced connecting a local repository with a GitHub repository.
  - Learned how to push local changes to GitHub using commands such as `git push origin main`.
  - Understood the relationship between local repositories, remote repositories, branches, and GitHub.

### Overall Learning

Today’s learning helped me understand more advanced Git concepts and how Git is integrated with GitHub for collaborative software development. I also gained a better understanding of how developers manage changes, maintain commit history, and host their projects remotely.
